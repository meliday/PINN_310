# Classroom heat-loss PINN: synthetic data

All data here is **synthetic**: generated by `generate_data.py` from a known physical model with known ground truth. None of it is a real measurement.

## Run

From the repository root, use a Python environment with NumPy, SciPy and
Matplotlib installed. Both `python -m ...` and direct script execution work;
default paths are relative to each script, independent of the working directory.

```bash
python -B -m unittest discover -s tests -v
python -B -m classroom_heat_pinn_data.synthetic.solver
python -B -m classroom_heat_pinn_data.synthetic.audit --skip-global-scan
# Optional coarse-grid diagnostic (14^3 solver calls, not a uniqueness proof):
python -B -m classroom_heat_pinn_data.synthetic.audit --scan-points 14
# Optional regeneration/figure; choose unused output paths:
python -B -m classroom_heat_pinn_data.synthetic.generate_data --output-dir /tmp/heat-synthetic-new
python -B -m classroom_heat_pinn_data.synthetic.plot_overview --output /tmp/heat-overview-new.png
```

Importing the helper modules does not load datasets, solve a problem, or write
outputs. Training must still never import the generation, audit or truth-plotting
modules. Generation defaults to `synthetic/generated/`, plotting to
`synthetic/generated/data_overview.png`; neither overwrites existing outputs.
The supplied `data/` remains the input snapshot. Audit and plotting read ground
truth only when explicitly called and are diagnostics, not fitting routines.

`ident.py` is a callable helper, not a standalone experiment. Its `run` and
`ident` functions now require an explicit corridor temperature; `ident` takes
it as a keyword: `thc=known['theta_inf']['N']`. Also pass
`dT=known['temperature_scaling']['DT_K']` when calling `ident`. With
`return_diagnostics=True`, it returns `(relative_std, correlation_S_N, diagnostics)`.
Diagnostics contain Jacobian rank, singular values and condition number. A
rank-deficient Jacobian has no reported covariance; `ident` raises a clear
`LinAlgError` instead of silently using an unstable inverse.

Solver `info['loss']` retains the signed Robin flux for compatibility.
`info['boundary_forcing']` contains the integrated extra flux `g` and
`info['total_flux']` is their wall-by-wall sum. Energy error now uses total flux,
with denominator `max(abs(q_in), 1e-12)`; absolute error is also available as
`info['balance_abs_err']`. This fixes forced-boundary diagnostics without changing
the discretisation or production solution (`g=0`). The manufactured problem's
own `theta_inf_N=0.9` remains intentional and is independent of production data.

## Model (nondimensional)

Room x ∈ [0, 1], y ∈ [0, 0.8] (10 m × 8 m), θ = (T − T_out) / 20 K, T_out = 0 °C.

- Interior: −∇·(k∇θ) = Q, with k = 1 and one Gaussian heater (x=0.2, y=0.6, A=8.65, s=0.15)
- Walls: −k ∂θ/∂n = Bi (θ − θ∞)
  - S (y=0) window wall: Bi = 1.0, θ∞ = 0
  - E (x=1) exterior wall: Bi = 0.4, θ∞ = 0
  - N (y=0.8) corridor wall: Bi = 0.25, θ∞ = 0.7 (14 °C)
  - W (x=0): adiabatic

Room temperature: median 18.0 °C, 5–95 % range 13.0–26.7 °C. True heat-loss shares: window 67.9 %, exterior 22.4 %, corridor 9.7 %.

| `config.json` | All ground truth (Bi, loss shares, seeds, mismatch settings) | Generation / evaluation only |
| `verification.json` | Solver checks | — |

Layout A: 6 sensors near walls + 4 interior. Layout B: 10 random interior points (seed 42). All sensors sit on grid nodes of both the 201 × 161 and 101 × 81 grids.

Mismatch model ("reality is messier"): k = 1 + 0.25 sin(2πx) sin(πy/0.8) plus a cold draft sink at the window frame (x=0.75, y=0.03) removing 10 % of the heater power. It differs from the simple model by RMS 1.28 °C (max 2.36 °C). Fit the *simple* model to this data and check whether the conclusion (which wall loses most) survives.

## Rigor audit (`python audit.py`)

- Scale invariance: (q, k_eff, h_i) → λ(q, k_eff, h_i) leaves T unchanged, so data identify only A ∝ q/k_eff and Bi_i = h_i L / k_eff. **The main experiment assumes A is known, i.e. q/k_eff is known.**
- Existence/uniqueness: k ≥ 0.75 > 0, Bi ≥ 0 with Bi > 0 on some wall → coercive bilinear form on H¹ (Lax–Milgram).
- Energy balance is exact by construction in the finite-volume solver, so for the solver it only checks bookkeeping; accuracy is checked by MMS and refinement. For a PINN it is a real check.
- Convergence on the actual problem (51→101→201→401): order 2.00, 2.00; estimated reference error 3e-4 °C (largest at the W–N corner).
- Local identifiability: reported Jacobian condition number 22.7; the script now prints rank before any covariance is used.
- The previous 30/30 random-start recovery claim and ≥0.58 °C distant-point misfit are historical reports, not reproduced by `audit.py`. The script runs a finite coarse-grid scan, now using interpolation at the original sensor coordinates rather than rounded positions. It does not prove global uniqueness or perform multi-start fitting.
- If A is also unknown: reported rel. std (Bi_S, Bi_E, Bi_N, A) = 2.4 %, 4.6 %, 30.6 %, 3.3 % at 0.1 °C; corr(A, Bi_N) = 0.97. The script recalculates this local diagnostic; it does not prescribe an identifiability conclusion for future inversions.
- Previously reported heat-loss shares at 0.1 °C (layout A): 67.9 ± 0.8, 22.4 ± 0.8, 9.7 ± 0.7 percentage points. Share uncertainty is not calculated by this script.

Local linear uncertainty assumes an accurate model and Gaussian noise. Exceeding
it alone does not establish optimization failure; noise realization, nonlinear
effects, bias and model mismatch must also be considered.
