# 강의실 열손실 추정: PINN vs FD-inverse vs RBF — 최종 보고 (합성 데이터)

작성 2026-11-07, Claude. 근거는 `results/metrics.csv`, 각 결과 폴더의 `summary.json`, 공동 기록 `AGENT_codexandclaude.md` (LOG 번호 표기). **모든 결과는 단순화한 2D 정상 열전도 모델의 합성 데이터, 센서 10개(layout A), 단일 잡음 실현, PINN은 seed 0 하나다.** 실측 데이터 결과가 아니다.

## 1. 결론

1. **이 문제에서는 FD-inverse가 기준선이다.** 같은 데이터·같은 미지수에서 FD는 모든 조건(기본, 냉각원, 내부 벽, 벽+냉각원)의 계수를 복원했고 한 번의 적합(여러 시작점 포함)이 모델 격자 101에서 1.5–4.2 s, 201에서 7.6–9.1 s다. PINN은 한 번 학습에 약 330–430 s다.
2. **PINN이 FD를 분명히 이긴 결과는 없다.** 기본 모델에서는 비슷했고(E3 noisy 0.042 vs 0.045°C, E5 mismatch 0.354 vs 0.364°C — 단일 조건의 작은 차이로 우위라 하지 않음), 확장 문제 두 곳에서는 실패했다.
   - **E5b 냉각원 세기:** FD는 복원(clean −0.04%, noisy −8.9%), PINN은 f→0으로 실패. 원 설정·Codex 대조 4개·Claude 사전 등록 대조 3개 모두 실패 → 사전 등록 규칙대로 종결 (LOG-072). 정답 계수를 고정하면 PINN도 장을 맞추므로(0.009°C) 표현력보다는 '장과 계수를 함께 학습하는 최적화'가 원인으로 보인다 (seed 하나·설정 몇 개에서의 관찰).
   - **X1 내부 벽:** 정답 Bi를 고정해도 PINN이 벽을 무시한 매끈한 장으로 수렴 (상대 L2 53.7%, LOG-086). 계수 추정 이전의 순방향 학습 실패이며, 원인(표현·학습 난이도, 학습 당시 W 경계점이 고체 덮인 구간에 일부 찍힌 결함 LOG-104)은 분리하지 않았다. 사용자 지시로 이후 PINN은 진행하지 않음.
3. **물리를 빠뜨리면 계수가 크게 틀린다 (FD 대조).** 벽을 무시하면 Bi_E·Bi_N이 하한까지 무너지고 온도 오차 6.6°C; 냉각원을 무시하면 온도는 0.2°C 수준으로 맞아도 Bi 오차가 최대 27%. 반대로 형상·냉각원 위치를 알려 주면 FD는 4미지수(Bi 3 + f)까지 복원했다.
4. **RBF 보간**은 계수를 주지 못하고 온도 복원도 0.5–0.7°C로 가장 나빴다.

## 6. 하지 않은 것·한계

- PINN: X1 구조 개선, X1·X2 PINN 역추정, E5b 교대 최적화·적응 가중 — 이 보고서 시점까지 미실행. 해커톤 이후 사용자가 사전 등록·시도 상한 안에서 재개를 허용했다 (PROJECT_PLAN §18, LOG-109); 그 결과는 이 보고서에 포함되지 않는다.
- 반복 평가 없음: 단일 잡음 실현, PINN seed 0 하나, 센서 배치 하나. 우위·안정성 주장 불가.
- 냉각원 위치 추정, E4·E6–E8, 실측 데이터 실험 미실행. 대화형 데모(`hackathon-demo/`, 로컬·git 미추적)는 네 조건의 저장 결과와 실시간 FD 재계산을 보여 준다 — 확장 조건 데이터는 연구 작업 트리에서 SHA-256을 기록해 내보냈다.
- X1/X2 열량 기준은 heater 진폭 고정 (벽 위 과열). 유효 열량 고정 비교는 미실행.
- X1 정답의 벽 끝 모서리 수치 불확실성: 201 노드에서 801↔1601 최대 0.0097°C (801 전체 노드 0.023°C).
- LOG-071–089 작업은 commit `40c0c01`(게시 이력 `5e18333`)에 있고 Codex가 LOG-104에서 독립 검증했다. LOG-104가 찾은 결함 3건은 LOG-105에서 보완했다 — 그중 X1 PINN 학습 경계가 서쪽 외벽의 고체 덮인 구간(y 0.30–0.34)에도 점을 찍던 문제는 **저장된 X1-c 결과가 이 수정 전의 학습**이라는 뜻이다. 그 기여도는 분리하지 않았다 (사용자 지시로 PINN 재학습 없음). LOG-109에서 외벽 노출 구간을 직접 계산하는 방식으로 바꿨고(전면 가림 지원), 고체가 있을 때 PINN의 난방·냉각 적분을 유체 영역 정확 적분으로 바꿨다 — 저장된 X1-c 학습에는 반영되지 않았다.
